# Banking Management System

A simple Banking Management System developed using **Java, JDBC, HTML, CSS, and JavaScript**. This project demonstrates core banking functionalities along with database connectivity using JDBC.
https://drive.google.com/file/d/1zyQPfbp4BsXo8uzVUJZW-REzCnEPWdht/view
## Features
- User Registration & Login
- Account Management
- Deposit & Withdrawal
- Balance Inquiry
- Transaction History
- Admin Dashboard
- Secure Database Connectivity using JDBC

## Tech Stack
- Java
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
